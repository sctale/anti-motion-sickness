# v0.2.0 重构实施计划

> **For agentic workers:** 按任务顺序执行。每个任务完成后 git commit 一次。

**Goal:** 修复现有 JS/TS 代码的关键 bug，补齐 Android 16 (API 36) 适配，规范化依赖、版本号、文档。

**Architecture:** 保留 RN 0.85 + Expo SDK 56；JS 层只做 UI + 控制；核心运动检测交给原生 Kotlin (OverlayService + SensorManager)；按 Android 16 规范加 16KB 页面对齐、预测性返回、大屏自适应。

**Tech Stack:** React Native 0.85.3, Expo SDK 56, TypeScript 6.0, Kotlin 2.x, Android 16 (API 36).

| 编号 | 缺口 | 处理 |
